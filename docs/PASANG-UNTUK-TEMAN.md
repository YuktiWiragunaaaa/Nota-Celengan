# Pasang Cukup di HP kamu

Cukup = aplikasi catatan keuangan. Semua data tersimpan **di HP kamu sendiri**, tanpa akun dan tanpa internet.

## Pasang
1. Buka file **Cukup-x.x.x.apk** yang dikirim ke kamu.
2. Kalau muncul peringatan "aplikasi tidak dikenal", ketuk **Setelan** → izinkan dari aplikasi ini (WhatsApp/Files/Drive) → kembali → **Instal**.
   - Xiaomi/HyperOS: kalau ada pemindaian keamanan, pilih **Tetap pasang**.
3. Buka Cukup dan ikuti 5 langkah awal (nama, dompet & saldo, jadwal gajian, rencana, izin).

## Supaya catat otomatis dari notifikasi bank/e-wallet jalan
1. Setelan Cukup → **Baca notifikasi e-wallet & bank** → nyalakan untuk Cukup.
2. Beri nama dompet sesuai bank-nya (BCA, Krom, OVO, DANA, dll.) supaya notifikasinya masuk ke dompet yang tepat.
3. Supaya tidak dimatikan sistem saat HP idle:
   - **Xiaomi/Redmi/POCO:** Setelan HP → Aplikasi → Cukup → Penghemat baterai: **Tanpa batasan**, dan nyalakan **Mulai otomatis**.
   - **Oppo/Realme/Vivo:** Setelan → Baterai → Cukup → izinkan aktivitas latar belakang & mulai otomatis.
   - **Samsung:** Setelan → Baterai → Batas penggunaan latar belakang → pastikan Cukup **tidak** ada di "Aplikasi tidur".

## Update
Kalau ada versi baru, buka file APK baru lalu pilih **Update**. Data tetap aman.

## Jaga-jaga
- Setelan → **Simpan cadangan** ke Google Drive sesekali. Kalau ganti HP, pilih "Punya file cadangan Cukup?" di layar pertama.
- Cukup juga membuat cadangan otomatis harian di HP.
- Menghapus aplikasi = semua data di HP ikut hilang (kecuali kamu punya file cadangan).
